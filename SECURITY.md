# Security

Destack takes security seriously and we appreciate responsible disclosures.

## Reporting a Vulnerability

Please report security issues privately:

- Email: florian@symbol.industries
- Discord: DM a maintainer privately
- Include the affected version or commit, a minimal reproduction, and impact
- If you can, include a PoC, exploit details, and suggested mitigation
- If you are unsure whether something is a vulnerability, report it anyway
- Do not open public issues or discussions for security reports

## Supported Versions

We currently support:

- The latest `main` branch
- The most recent public release
Security fixes are released for supported versions only.

## Safe Harbor

We consider security research in good faith and in accordance with this policy to be authorized.
We will not pursue legal action against researchers for good faith, non destructive testing.

## Non Security Issues

For non sensitive issues, please use the normal issue tracker or Discord.
