# Destack RS System

System implementation for Destack using Rust.

## Structure

This is a Cargo workspace containing the following crates:

- `destack_system` - Main system implementation crate

## Building

```bash
cargo build
```

## Running

```bash
cargo run -p destack_system
```

## Dependencies

The crates in this workspace depend on the local `destack` crate from the `destack-rs` workspace.

## Development

This workspace uses Rust 1.88.0 or later.
