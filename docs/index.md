# Destack Documentation

Destack is an integrated language, toolchain, runtime, and library for building software from
strict TypeScript-shaped source.

## Start Here

- [Overview](overview.md): understand the language, toolchain, runtime, and broader stack.
- [Comparison](comparison.md): compare Destack with TypeScript and adjacent systems.
- [Language](language/index.md): learn the language and its relationship to strict TypeScript.
- [Runtime](language/runtime/index.md): understand execution, effects, and host bindings.

## Install Destack

Install the current release and create a new application:

```bash
curl -fsSL https://destack.sh/install | sh
destack new my-destack-app
```
