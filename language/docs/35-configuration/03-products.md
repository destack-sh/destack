# Products

Product assembled from one or more build targets.

| Field | Description |
| --- | --- |
| `targets` | Target names keyed by product role. |
| `stability` | Stability promised by this product. |
| `modes` | Active source graph modes for this product. |
| `roles` | Active source graph roles for this product. |
| `features` | Active source graph features for this product. |
