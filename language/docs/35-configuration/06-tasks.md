# Tasks

Named toolchain or shell invocation.

| Field | Description |
| --- | --- |
| `run` | Destack command name to run. |
| `exec` | Explicit shell command to execute. |
| `target` | Build target selected for this task. |
| `product` | Product selected for this task. |
| `profile` | Profile selected for this task. |
