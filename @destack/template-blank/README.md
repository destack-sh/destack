# @destack/template-blank

Show an empty page with Destack's mark.

## Overview

`@destack/template` is the package `destack new` copies as a new package's start: one view, `start`, showing the mark on the brand's orange.

## Reference

| Export | What it is |
| --- | --- |
| `@destack/template-blank/package` | The package, titled Template. |
| `@destack/template-blank/view` | The `start` view. |

## Examples

Start a new package from it:

```sh
destack new @example/notes
```
