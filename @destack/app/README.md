# @destack/app

Show an empty page with Destack's mark: the app a space and a new package start from.

## Overview

`@destack/app` is the smallest app: one view, `start`, showing the mark on the brand's orange.
Spaces install it until they install their own apps, and `destack new` copies it as a new package's start.

## Reference

| Export | What it is |
| --- | --- |
| `@destack/app/package` | The package, titled App. |
| `@destack/app/view` | The `start` view. |

## Examples

Start a new package from it:

```sh
destack new @example/notes
```
